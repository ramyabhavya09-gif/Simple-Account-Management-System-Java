# Simple Account Management System using Java

## Project Description
The Simple Account Management System is a basic Java application developed using Object-Oriented Programming (OOP) concepts. It performs simple account operations such as depositing money, withdrawing money and displaying the final account balance.

## Features
- Enter customer name.
- Enter initial balance.
- Deposit amount.
- Withdraw amount.
- Check available balance.
- Display customer details.
- Check insufficient balance.

## Technologies Used
- Java
- Scanner Class
- HTML
- CSS
- JavaScript

## OOP Concepts Used
1. Class and Object
2. Encapsulation
3. Constructor
4. Methods

## Project Files
- `BankManagement1.java` – Java source code.
- `index.html` – Webpage structure.
- `style.css` – Webpage design.
- `script.js` – Account operations.
- `README.md` – Project documentation.

## How to Run

1. Install Java JDK.
2. Open the project in a Java IDE.
3. Compile:

   `javac BankManagement1.java`

4. Run:

   `java BankManagement1`

## Conclusion
This project demonstrates basic account management operations using Java and OOP concepts. It helps understand classes, objects, constructors, encapsulation and methods.
